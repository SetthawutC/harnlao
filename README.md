# 🧾 หารเหล้า (Harnlao)

แอปพลิเคชันเว็บตัวเล็กๆ น่ารัก สำหรับช่วยแก๊งเพื่อน "หารค่าบิล" เวลาไปกินข้าวหรือปาร์ตี้ด้วยกัน หมดปัญหาเรื่องใครกินอะไร ใครต้องจ่ายเท่าไหร่!

สามารถพิมพ์ชื่อคน เพิ่มรายการอาหาร เลือกคนที่ต้องหารในรายการนั้นๆ และแอปจะคำนวณยอดรวมของแต่ละคนให้อัตโนมัติ พร้อมทั้งเซฟบิลสรุปยอดเป็นรูปภาพส่งเข้าไลน์กลุ่มได้เลย!

## ✨ ฟีเจอร์หลัก
- 🧑‍🤝‍🧑 **เพิ่มเพื่อนร่วมโต๊ะ:** ใส่รายชื่อคนที่มากินด้วยกัน
- 📝 **เพิ่มรายการอาหาร/เครื่องดื่ม:** ระบุชื่อรายการ ราคา และเลือกว่าใครเป็นคนหารเมนูนี้บ้าง
- 🧮 **คำนวณอัตโนมัติ:** สรุปยอดรวมที่แต่ละคนต้องจ่ายให้อย่างแม่นยำ
- 📸 **แคปใบเสร็จ:** บันทึกใบสรุปยอดเป็นรูปภาพ (พร้อมแนบ QR Code รับเงิน) เอาไปแปะในกลุ่มแชทได้ทันที

## 🛠️ Tech Stack ที่ใช้
โปรเจกต์นี้ถูกสร้างขึ้นด้วยเทคโนโลยีเหล่านี้เพื่อให้ทำงานได้รวดเร็วและสวยงาม:
- **[React](https://react.dev/)** - ไลบรารีสำหรับสร้าง User Interface สุดฮิต
- **[Vite](https://vitejs.dev/)** - เครื่องมือ Build โปรเจกต์ที่ทำงานได้เร็วปรู๊ดปร๊าด
- **[Tailwind CSS](https://tailwindcss.com/)** - สำหรับจัดการความสวยงาม (Styling) ให้กับหน้าเว็บ
- **[html-to-image](https://github.com/bubkoo/html-to-image)** - ไลบรารีสำหรับแปลงหน้าเว็บใบเสร็จให้กลายเป็นรูปภาพ

## 🚀 วิธีการรันโปรเจกต์ในเครื่องตัวเอง

ถ้าอยากเอาไปรันเล่นหรือพัฒนาต่อ ทำตามขั้นตอนง่ายๆ นี้ได้เลยครับ

1. **ติดตั้ง Dependencies:**
   เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วพิมพ์
   ```bash
   npm install
   ```

2. **รันโปรเจกต์ (โหมดนักพัฒนา):**
   ```bash
   npm run dev
   ```

3. **เปิดดูในเบราว์เซอร์:**
   คลิกที่ลิงก์ที่แสดงใน Terminal (ปกติจะเป็น `http://localhost:5173`)

## 📦 วิธีการ Build สำหรับนำไปใช้งานจริง (Deploy)
ถ้าพร้อมเอาขึ้นเซิร์ฟเวอร์แล้ว ให้พิมพ์คำสั่งนี้:
```bash
npm run build
```
ไฟล์ทั้งหมดที่พร้อมใช้งานจะอยู่ในโฟลเดอร์ `dist` ซึ่งสามารถนำไปฝากไว้บนโฮสติ้งต่างๆ อย่าง Vercel, Netlify หรือ GitHub Pages ได้เลยครับ
